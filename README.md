# Coffee-Shop-Management-System
Dự án Quản lý Nhân viên và Cửa hàng Cà phê (Coffee Shop Management System). Nó bao gồm đầy đủ các khái niệm cốt lõi của Backend: Cơ sở dữ liệu (Database), API, Xác thực (Authentication) và Logic nghiệp vụ.
